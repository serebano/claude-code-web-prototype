# Font resource provenance

These resources are byte-for-byte copies from the user-selected local `/Applications/Claude.app`, added on 2026-10-15 for the requested private UI reconstruction. `manifest.json` records original paths, sizes and SHA-256 identities. Their normal/italic variable faces and 300–800 weight ranges follow the installed renderer CSS `c6a992d55-sXiDGMFQ.css`.

Embedded attribution: copyright 2025–2026 Anthropic PBC; manufacturer BSPK LLC; designer BSPK x Geist x Anthropic; version 26.179.2. These resources are not original prototype artwork or open-source substitutes. No license grant is asserted by their presence here. The metadata audit in `docs/SOURCE-AUDIT.md` records the bounded license-metadata observations.

The interface and settings now use Anthropic Sans; the Serif chat setting and preview use Anthropic Serif. Explicit System and system-monospace preferences retain platform stacks. Browser/OS rendering, optical sizing, antialiasing and scaling still affect screenshot pixels even with identical font bytes.

The additional Anthropicons-Variable resource replaces approximate stroke icons using the installed renderer’s name/code-point map and optical weight calculation. See `docs/ICON-AUDIT.md` for provenance, observed mappings and animation limits.

Two SVG resources were captured from rendered web settings DOM: Reflect navigation and Chrome illustration. Their identities are in web-artwork-manifest.json. The Chrome root currentColor was resolved to its observed rgb(240,239,236); the navigation glyph remains a CSS mask.
